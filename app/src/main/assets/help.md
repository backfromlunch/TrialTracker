## TrialTracker Help

TrialTracker allows you to conveniently record repeated daily observations during a short-term personal trial.

### Initial Startup

The organiser (hospital, laboratory, workplace) of your trial will provide you with a pair of configuration files. You should download these files to your device before you start TrialTracker because TrialTracker (by design) has no internet access.

The first time you run TrialTracker it will ask you to provide these two files:
- 'service request' which describes the trial as a whole and how long it runs
- 'trial questionnaire' describes all the questions that need to be asked

### Pages

#### Entry

Fill in the fields for this entry.
The ENTER key will generally move you to the next field, or you can just select the field you wish to enter by scrolling and clicking.
Data is saved on every keystroke - there is no SAVE button.

The date selector at the top will allow you to navigate to previous dates and see the entries. Depending on the settings you may be able to edit those earlier entries.

#### Summary

The Summary page will show you which dates have partially or fully completed entries.
If you tap on a date, you will jump to that date's entry page (so long as that date is valid for the trial).
You can't jump to future dates.

#### Trial and Questionnaire

Here you can review the two configuration files and the settings they have provided for your use of TrialTracker. You can check the version of the TrialTracker app.

#### Export

The export page will allow you to export all the data entered for the trial so far.
This will be saved in your device's file system with a name chosen by you.
At the end of the trial period, the organiser may ask you to return this to them.

#### Settings

By default, previous entries are visible but not editable. If you want permission to edit previous entries you can change the setting here.

You can also set the colour scheme.

### Data Security and Privacy

TrialTracker requests **no Android permissions at all** — not internet, storage, or camera. It cannot connect online, and file import/export uses Android's own file picker, which needs no special access.

Android's auto-backup is switched off, so none of TrialTracker's data is backed up. If your device is lost, damaged or stolen, you will lose all your data — there is no recovery.
